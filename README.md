# My First C# API

This repository marks a personal milestone: my very first API built from scratch using **C#**.

## Project Overview
Even though it is a basic project, I wanted to document my progress and keep a record of my learning journey. To make it fully functional, I also included a `.http` file, allowing you to test and complete all **CRUD operations** directly from the editor, no matter how simple the setup looks.

## Future Updates
Looking ahead, I intend to progressively refine the codebase and implement new functionalities as time permits. This ongoing effort will serve as a personal commitment to consistency and a tangible record of my professional growth.
